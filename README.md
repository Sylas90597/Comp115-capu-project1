City Skyline Art Project with Python

This project creates a nighttime city skyline of a big city with a body of water in front for the reflections of the buildings adding hopefully a more detailed look. The buildings each have many small details to give them each a more unique and realistic look which i am very pleased with, as well as showing off many lights from windows that have clear reflections in the water.

I am happy that i was able to make my vision come to life, but there are a lot of things that i would fix or improve if i was able to work faster, That also includes making my code more clean and tidy. But because overall i am happy with it i think i will continue to work on improving it i my own time for my own pleasure.
